# get-carbuddy

Landing page CarBuddy: aplikasi Android untuk mencatat odometer, BBM, servis, pajak, dan asuransi kendaraan. Local-first, tanpa akun, offline penuh.

Halaman ini live di [https://azmirizkifar20.github.io/get-carbuddy/](https://azmirizkifar20.github.io/get-carbuddy/).

Satu file HTML mandiri (`index.html`) plus aset gambar — tanpa build step. Di-hosting gratis oleh GitHub Pages.
